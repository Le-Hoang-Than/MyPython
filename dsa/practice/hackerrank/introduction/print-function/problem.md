# Print Function

Đoạn mã mẫu đi kèm sẽ đọc một số nguyên $n$ từ STDIN.

Không sử dụng bất kỳ phương thức xử lý chuỗi (string methods) nào, hãy cố gắng in ra dãy số sau:$123...n$

Lưu ý rằng "..." đại diện cho các giá trị liên tiếp ở giữa.

**Example**

$n$ = 5

In ra chuỗi 12345

**Input Format**

Dòng đầu tiên chứa một số nguyên $n$.

**Constraints**

$1 \le n \le 150$

**Output Format**

In danh sách các số nguyên từ $1$ đến $n$ dưới dạng một chuỗi, không có khoảng trắng.

**Sample Input 0**
```markdown
3
```

**Sample Output 0**

```markdown
123
```
