# Loops

**Task**

Đoạn mã có sẵn sẽ đọc một số nguyên $n$ từ đầu vào (STDIN).

Với tất cả các số nguyên không âm $i < n$, hãy in ra giá trị $i^2$.

**Example**

$n = 3$

Danh sách các số nguyên không âm nhỏ hơn $n = 3$ là $[0, 1, 2]$.

In bình phương của mỗi số trên một dòng riêng biệt:

```markdown
0
1
4
```

**Input Format**

Dòng đầu tiên và duy nhất chứa số nguyên $n$.

**Constraints**

$1 \le n \le 20$

**Output Format**

In ra $n$ dòng, mỗi dòng tương ứng với giá trị $i^2$

**Sample Input 0**

```markdown
5
```

**Sample Output 0**

```markdown
0
1
4
9
16
```
