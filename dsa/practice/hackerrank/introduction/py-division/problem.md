# Python: Division

**Task**

Đoạn mã mẫu được cung cấp sẽ đọc hai số nguyên, $a$ và $b$,
từ STDIN (luồng nhập chuẩn).
Hãy bổ sung logic để in ra hai dòng.
Dòng đầu tiên chứa kết quả của phép chia lấy phần nguyên,
$a$ // $b$. Dòng thứ hai chứa kết quả của phép chia số thực,
$a$ / $b$.

Không cần làm tròn hoặc định dạng kết quả.

**Example**

$a$ = 3
$b$ = 5
- Kết quả của phép chia lấy phần nguyên là 3 // 5 = 0.
- Kết quả của phép chia số thực là 3 / 5 = 0.6.

Print:
```markdown
0
0.6
```

**Input Format**

Dòng đầu tiên chứa số nguyên thứ nhất, $a$.

Dòng thứ hai chứa số nguyên thứ hai, $b$.

**Output Format**
In ra hai dòng theo mô tả ở trên.

**Sample Input 0**

```markdown
4
3
```

**Sample Output 0**

```markdown
1
1.33333333333
```
