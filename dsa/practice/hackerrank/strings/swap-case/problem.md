# sWAP cASE

Bạn được cho một chuỗi ký tự và nhiệm vụ của bạn là đảo ngược kiểu chữ (swap cases). Nói cách khác, hãy chuyển tất cả các chữ cái viết thường thành chữ viết hoa và ngược lại.

**For Example:**

```markdown
Www.HackerRank.com → wWW.hACKERrANK.COM
Pythonist 2 → pYTHONIST 2
```

**Function Description**

Hãy hoàn thành hàm swap_case trong trình soạn thảo bên dưới.

Hàm swap_case có tham số sau:
- string s: chuỗi ký tự cần chỉnh sửa.

**Returns**

- string: chuỗi đã được thay đổi kiểu chữ.

**Input Format**

Một dòng duy nhất chứa chuỗi ký tự $s$.

**Constraints**

$0 < \text{len(s)} \le 1000$

**Sample Input 0**

```markdown
HackerRank.com presents "Pythonist 2".
```

**Sample Output 0**

```markdown
hACKERrANK.COM PRESENTS "pYTHONIST 2".
```
