| Phương thức                     | Viết tắt | Mô tả                                                                          |
|:--------------------------------|:---------|:-------------------------------------------------------------------------------|
| `add()`                         |          | Thêm một phần tử vào tập hợp.                                                  |
| `clear()`                       |          | Xóa toàn bộ các phần tử khỏi tập hợp.                                          |
| `copy()`                        |          | Trả về một bản sao của tập hợp.                                                |
| `difference()`                  | `-`      | Trả về một tập hợp mới chứa các phần tử chỉ có ở tập hợp này.                  |
| `difference_update()`           | `-=`     | Xóa các phần tử trong tập hợp này nếu chúng cũng xuất hiện trong tập hợp khác. |
| `discard()`                     |          | Xóa một phần tử cụ thể (không báo lỗi nếu không có).                           |
| `intersection()`                | `&`      | Trả về một tập hợp mới là giao của các tập hợp.                                |
| `intersection_update()`         | `&=`     | Giữ lại các phần tử có mặt trong tất cả các tập hợp được chỉ định.             |
| `isdisjoint()`                  |          | Kiểm tra xem hai tập hợp có giao nhau hay không.                               |
| `issubset()`                    | `<=`     | Kiểm tra xem tập hợp này có là tập con của tập khác không.                     |
|                                 | `<`      | Kiểm tra xem tập hợp này có là tập con thực sự không.                          |
| `issuperset()`                  | `>=`     | Kiểm tra xem tập hợp này có là tập cha của tập khác không.                     |
|                                 | `>`      | Kiểm tra xem tập hợp này có là tập cha thực sự không.                          |
| `pop()`                         |          | Xóa và trả về một phần tử bất kỳ.                                              |
| `remove()`                      |          | Xóa một phần tử cụ thể (báo lỗi nếu không có).                                 |
| `symmetric_difference()`        | `^`      | Trả về hiệu đối xứng của hai tập hợp.                                          |
| `symmetric_difference_update()` | `^=`     | Cập nhật tập hợp bằng hiệu đối xứng.                                           |
| `union()`                       | `\|`     | Trả về hợp của các tập hợp.                                                    |
| `update()`                      | `\|=`    | Cập nhật tập hợp bằng hợp của nó và các tập hợp khác.                          |
