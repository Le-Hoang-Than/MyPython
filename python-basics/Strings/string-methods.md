| Phương thức      | Mô tả                                                   |
|:-----------------|:--------------------------------------------------------|
| `capitalize()`   | Chuyển đổi ký tự đầu tiên thành chữ hoa.                |
| `casefold()`     | Chuyển đổi chuỗi thành chữ thường (so khớp mạnh).       |
| `center()`       | Căn giữa chuỗi.                                         |
| `count()`        | Đếm số lần xuất hiện của một giá trị.                   |
| `encode()`       | Mã hóa chuỗi.                                           |
| `endswith()`     | Kiểm tra chuỗi kết thúc bằng giá trị nào đó.            |
| `expandtabs()`   | Thiết lập kích thước khoảng cách tab.                   |
| `find()`         | Tìm kiếm vị trí của giá trị (trả về -1 nếu không thấy). |
| `format()`       | Định dạng giá trị trong chuỗi.                          |
| `format_map()`   | Định dạng giá trị bằng một mapping.                     |
| `index()`        | Tìm kiếm vị trí của giá trị (báo lỗi nếu không thấy).   |
| `isalnum()`      | Kiểm tra nếu chuỗi là chữ và số.                        |
| `isalpha()`      | Kiểm tra nếu chuỗi chỉ toàn chữ cái.                    |
| `isascii()`      | Kiểm tra ký tự ASCII.                                   |
| `isdecimal()`    | Kiểm tra số thập phân.                                  |
| `isdigit()`      | Kiểm tra chữ số.                                        |
| `isidentifier()` | Kiểm tra định danh hợp lệ.                              |
| `islower()`      | Kiểm tra chữ thường.                                    |
| `isnumeric()`    | Kiểm tra ký tự số.                                      |
| `isprintable()`  | Kiểm tra ký tự in được.                                 |
| `isspace()`      | Kiểm tra khoảng trắng.                                  |
| `istitle()`      | Kiểm tra định dạng tiêu đề.                             |
| `isupper()`      | Kiểm tra chữ hoa.                                       |
| `join()`         | Nối các phần tử vào chuỗi.                              |
| `ljust()`        | Căn lề trái.                                            |
| `lower()`        | Chuyển thành chữ thường.                                |
| `lstrip()`       | Xóa khoảng trắng bên trái.                              |
| `maketrans()`    | Tạo bảng dịch ký tự.                                    |
| `partition()`    | Chia chuỗi thành 3 phần.                                |
| `replace()`      | Thay thế giá trị.                                       |
| `rfind()`        | Tìm vị trí cuối cùng của giá trị.                       |
| `rindex()`       | Tìm vị trí cuối cùng của giá trị (báo lỗi).             |
| `rjust()`        | Căn lề phải.                                            |
| `rpartition()`   | Chia chuỗi thành 3 phần từ bên phải.                    |
| `rsplit()`       | Cắt chuỗi từ bên phải.                                  |
| `rstrip()`       | Xóa khoảng trắng bên phải.                              |
| `split()`        | Cắt chuỗi thành danh sách.                              |
| `splitlines()`   | Cắt chuỗi theo dòng.                                    |
| `startswith()`   | Kiểm tra chuỗi bắt đầu bằng giá trị nào đó.             |
| `strip()`        | Xóa khoảng trắng hai đầu.                               |
| `swapcase()`     | Đổi hoa thành thường và ngược lại.                      |
| `title()`        | Viết hoa đầu mỗi từ.                                    |
| `translate()`    | Thay thế ký tự theo bảng dịch.                          |
| `upper()`        | Chuyển thành chữ hoa.                                   |
| `zfill()`        | Thêm số 0 vào đầu chuỗi.                                |
