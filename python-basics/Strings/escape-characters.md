| Mã (Code) | Kết quả         | Mô tả                             |
|:----------|:----------------|:----------------------------------|
| `\`       | Single Quote    | Chèn một dấu nháy đơn.            |
| `\\`      | Backslash       | Chèn một dấu gạch chéo ngược.     |
| `\n`      | New Line        | Xuống dòng mới.                   |
| `\r`      | Carriage Return | Đưa con trỏ về đầu dòng.          |
| `\t`      | Tab             | Chèn một khoảng trắng Tab.        |
| `\b`      | Backspace       | Xóa ngược một ký tự.              |
| `\f`      | Form Feed       | Ngắt trang.                       |
| `\ooo`    | Octal value     | Chèn ký tự theo hệ bát phân.      |
| `\xhh`    | Hex value       | Chèn ký tự theo hệ thập lục phân. |
