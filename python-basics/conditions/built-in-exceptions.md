| Ngoại lệ (Exception)  | Mô tả                                   |
|:----------------------|:----------------------------------------|
| **ArithmeticError**   | Lỗi trong các phép tính toán số học.    |
| **AssertionError**    | Câu lệnh `assert` bị sai.               |
| **AttributeError**    | Tham chiếu hoặc gán thuộc tính bị lỗi.  |
| **ImportError**       | Module được import không tồn tại.       |
| **IndexError**        | Chỉ số của danh sách không tồn tại.     |
| **KeyError**          | Khóa không tồn tại trong dictionary.    |
| **NameError**         | Biến chưa được định nghĩa.              |
| **SyntaxError**       | Lỗi cú pháp code.                       |
| **TypeError**         | Kết hợp các kiểu dữ liệu không phù hợp. |
| **ValueError**        | Giá trị truyền vào hàm không hợp lệ.    |
| **ZeroDivisionError** | Chia cho số không.                      |
