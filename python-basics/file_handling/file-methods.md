| Phương thức        | Mô tả                                      |
|:-------------------|:-------------------------------------------|
| **`close()`**      | Đóng tệp đang mở.                          |
| **`detach()`**     | Tách luồng thô ra khỏi bộ đệm.             |
| **`fileno()`**     | Trả về số định danh luồng từ hệ điều hành. |
| **`flush()`**      | Làm trống bộ đệm nội bộ.                   |
| **`isatty()`**     | Kiểm tra luồng tệp có tương tác hay không. |
| **`read()`**       | Trả về nội dung tệp.                       |
| **`readable()`**   | Kiểm tra tệp có thể đọc không.             |
| **`readline()`**   | Trả về một dòng từ tệp.                    |
| **`readlines()`**  | Trả về danh sách các dòng.                 |
| **`seek()`**       | Thay đổi vị trí con trỏ tệp.               |
| **`seekable()`**   | Kiểm tra tệp có cho phép dùng seek không.  |
| **`tell()`**       | Trả về vị trí con trỏ hiện tại.            |
| **`truncate()`**   | Điều chỉnh kích thước tệp.                 |
| **`writable()`**   | Kiểm tra tệp có thể ghi không.             |
| **`write()`**      | Ghi chuỗi vào tệp.                         |
| **`writelines()`** | Ghi danh sách chuỗi vào tệp.               |
