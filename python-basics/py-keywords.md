### Danh sách các Từ khóa trong Python (Keywords)

Từ khóa là các từ đã được dành riêng, không thể sử dụng chúng làm tên biến, tên hàm hoặc bất kỳ định danh nào khác.

| Từ khóa      | Mô tả                                                        |
|:-------------|:-------------------------------------------------------------|
| **and**      | Toán tử logic VÀ.                                            |
| **as**       | Tạo bí danh (alias).                                         |
| **assert**   | Dùng để kiểm tra điều kiện khi gỡ lỗi (debugging).           |
| **async**    | Định nghĩa một hàm bất đồng bộ.                              |
| **await**    | Chờ kết quả từ một hàm bất đồng bộ.                          |
| **break**    | Thoát khỏi vòng lặp.                                         |
| **case**     | Dùng để so sánh mẫu trong câu lệnh `match`.                  |
| **class**    | Định nghĩa một lớp (class).                                  |
| **continue** | Nhảy đến lần lặp kế tiếp của vòng lặp.                       |
| **def**      | Định nghĩa một hàm.                                          |
| **del**      | Xóa một đối tượng.                                           |
| **elif**     | Viết tắt của "else if", dùng trong câu lệnh điều kiện.       |
| **else**     | Trường hợp còn lại trong câu lệnh điều kiện hoặc vòng lặp.   |
| **except**   | Xử lý lỗi trong khối lệnh `try...except`.                    |
| **False**    | Giá trị Boolean sai.                                         |
| **finally**  | Khối mã luôn được thực thi dù có lỗi hay không.              |
| **for**      | Tạo vòng lặp với số lần biết trước.                          |
| **from**     | Nhập các phần cụ thể từ một module.                          |
| **global**   | Khai báo biến toàn cục.                                      |
| **if**       | Câu lệnh điều kiện.                                          |
| **import**   | Nhập module vào chương trình.                                |
| **in**       | Kiểm tra sự tồn tại trong một tập hợp.                       |
| **is**       | Kiểm tra xem hai biến có cùng trỏ đến một đối tượng không.   |
| **lambda**   | Tạo hàm ẩn danh (hàm một dòng).                              |
| **match**    | Bắt đầu câu lệnh khớp mẫu (Python 3.10+).                    |
| **None**     | Đại diện cho giá trị rỗng hoặc không tồn tại.                |
| **nonlocal** | Khai báo biến thuộc phạm vi bao ngoài (không phải toàn cục). |
| **not**      | Toán tử logic phủ định.                                      |
| **or**       | Toán tử logic HOẶC.                                          |
| **pass**     | Câu lệnh giữ chỗ, không thực hiện gì cả.                     |
| **raise**    | Tự kích hoạt một ngoại lệ (error).                           |
| **return**   | Trả về giá trị và thoát khỏi hàm.                            |
| **True**     | Giá trị Boolean đúng.                                        |
| **try**      | Bắt đầu khối lệnh kiểm tra lỗi.                              |
| **while**    | Tạo vòng lặp theo điều kiện.                                 |
| **with**     | Quản lý ngữ cảnh (thường dùng để mở file tự động đóng).      |
| **yield**    | Trả về kết quả cho hàm generator.                            |
