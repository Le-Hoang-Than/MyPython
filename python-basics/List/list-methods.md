# Python - List Methods
| Phương thức | Mô tả                                                                |
|:------------|:---------------------------------------------------------------------|
| `append()`  | Thêm một phần tử vào cuối danh sách.                                 |
| `clear()`   | Xóa tất cả các phần tử khỏi danh sách.                               |
| `copy()`    | Trả về một bản sao của danh sách.                                    |
| `count()`   | Trả về số lượng phần tử có giá trị cụ thể.                           |
| `extend()`  | Thêm các phần tử của một danh sách khác vào cuối danh sách hiện tại. |
| `index()`   | Trả về vị trí của phần tử đầu tiên có giá trị cụ thể.                |
| `insert()`  | Thêm một phần tử vào vị trí xác định.                                |
| `pop()`     | Xóa phần tử tại vị trí xác định.                                     |
| `remove()`  | Xóa phần tử có giá trị cụ thể.                                       |
| `reverse()` | Đảo ngược thứ tự các phần tử.                                        |
| `sort()`    | Sắp xếp danh sách.                                                   |
